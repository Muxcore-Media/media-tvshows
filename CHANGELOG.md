# Changelog

## v0.1.0 (2026-06-14)

- Initial release
- Series/season/episode hierarchy with SQLite storage
- `TvManagementService` gRPC API (add, remove, list, get, refresh, monitoring)
- `MediaAdminService` contract implementation for admin UI integration
- Artwork serving via HTTP file server
- Per-episode and per-season monitoring with season-to-episode cascade
